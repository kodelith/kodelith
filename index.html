Orbit is a browser-based code editor for building and testing websites. Write HTML, style pages with CSS, add JavaScript, and see your changes in a live preview — without installing a desktop editor.

How to use the Orbit online code editor

  1. Open the editor and create a project.
  2. Create or open an HTML, CSS or JavaScript file and write your code.
  3. Use Live Preview to run your page and check the result.

Frequently asked questions

Is Orbit a free online code editor?

Yes. Orbit is currently available as a free browser-based workspace for writing and previewing HTML, CSS and JavaScript.

Can I write HTML, CSS and JavaScript in Orbit?

Yes. Orbit brings HTML, CSS and JavaScript editing together with a live website preview.

Do I need to install a code editor?

No desktop installation is required to use Orbit. Open the website in a modern browser and start a project.

Can I preview a website while coding?

Yes. Orbit includes a live preview panel and device-size options for checking your website as you work.

Can I connect my own AI provider?

Yes. You can connect an OpenAI-compatible provider using your own API key. The key stays in the current browser tab and is not saved to your Orbit account.

Connect your own AI

Use an API key from an OpenAI-compatible provider. Orbit sends requests directly from this browser to the provider you choose. Your key is held in memory for this tab only; it is not saved to your Orbit account or project.

◆ Never paste your key into project code. Orbit does not store it. Closing or refreshing this tab clears it.
Choose a provider, enter its model and API key, then connect.

Before connecting

Your provider may charge for API usage. Check its pricing and usage limits first. Only OpenAI-compatible chat-completions endpoints are supported. Your provider must allow browser CORS requests. Custom endpoints must use HTTPS (or localhost).
